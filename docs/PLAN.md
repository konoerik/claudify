Wiring: rule injected into marker-delimited `## Add-ons` section of kit-owned `.claude/claudify.md` (blank at init); installed set recorded as `addons:` line in `.claude/claudify` so `update` can reassemble (re-fetch base, re-inject each rule). Global command gets an add-ons table + `## Steps: add`. Overload contract: one conditional trigger line per add-on (schema cannot express always-load), every add-on doc leads with a Quick Reference, docs are indexes — raw data stays cold until explicitly asked. guard-naming.sh is a blocklist, needs no change. v1 shipped (ADR-13) — see Done. Docs-relocation prerequisite dropped (ADR-12) — add-on docs land in bare `docs/` like everything else; add-on doc names (PEOPLE.md, TRANSCRIPTS.md) are distinctive enough that collision risk stays low. Paused here to get real usage of people/transcripts before building the roster below
